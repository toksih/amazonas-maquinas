# Amazonas Máquinas

Site institucional estático da Amazonas Máquinas, criado com HTML5, CSS3 e
JavaScript puro. O projeto funciona abrindo o arquivo `index.html` diretamente
e também pode ser publicado no GitHub Pages ou Cloudflare Pages.

## Como visualizar

Abra `index.html` no navegador. Não é necessário instalar dependências.

## Alterações futuras

- **WhatsApp:** altere os contatos no início de `js/script.js`, dentro da
  constante `whatsappContacts`. O número final **4707** é exclusivo para vendas
  e orçamentos; o número final **2524** é exclusivo para suporte e manutenção.
- **Facebook:** substitua o texto `Facebook • link a adicionar`, no rodapé do
  `index.html`, por um link quando a URL estiver disponível.
- **Parceiros:** na seção `#parceiros`, substitua cada bloco
  `.partner-placeholder` por uma tag `<img>` com o logo correspondente. Salve os
  arquivos em `images/lojas/`.
- **Open Graph:** após definir o domínio definitivo, troque `og:image` no
  `index.html` por uma URL absoluta da imagem de compartilhamento.
- **Novas máquinas:** duplique um bloco `.product-card` na seção `#maquinas`,
  atualize foto, textos, especificações e a mensagem em `data-message`.

## Observações sobre o conteúdo

- Os dois banners comparativos fornecidos serviram somente como referência de
  conteúdo e não aparecem no site.
- A foto da Máquina Basic de 1 bico foi gerada como imagem ilustrativa com base
  nas referências fornecidas.
- A Máquina Premium usa a foto real enviada.
- Capacidades e estimativas de produção devem ser confirmadas com a loja antes
  da venda.
- Os espaços de quatro parceiros foram mantidos propositalmente como
  marcadores para receber os logos depois.
